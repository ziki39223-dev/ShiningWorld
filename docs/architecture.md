## 层 1 · 顶层链路（固定不变）

```
┌──────────────────────────────────────────────────────────┐
│  DSH 九宫格主控台（MCP 客户端）                            │
│  一个窗口，3×3 网格，9 张支线卡片                           │
└───────────────────────────┬──────────────────────────────┘
                            │ MCP（stdio / SSE 双协议，仅一条连接）
┌───────────────────────────▼──────────────────────────────┐
│  闪亮大世界自研 MCP 调度服务（唯一核心服务）                 │
│  shining-world v1.0.0 · 45 个工具                          │
└───────────────────────────┬──────────────────────────────┘
                            │ 模型适配器层（统一 complete 接口）
┌───────────────────────────▼──────────────────────────────┐
│  多家 OpenAI 兼容 API                                      │
│  付费 API + 免费 API 池 · 自动负载 / 重试 / 故障切换         │
└──────────────────────────────────────────────────────────┘
```

**三条不可动摇的边界**

1. 工作台固定 DSH，仅配置一条 MCP 连接 —— 不接 Trae / Qoder / WorkBuddy CLI，不接第三方 MCP，无子进程、无账号轮换。
2. 服务内部只依赖标准 OpenAI 兼容协议 —— 免费池与付费池在适配器层完全同构，只是 `tier` 与 `priority` 不同。
3. 上行的只有工具调用，下行的只有统一信封 —— 客户端永远看不到裸异常（`{ok:false, error:{code,message,detail}}`）。
